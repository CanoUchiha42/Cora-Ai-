# Cora AI — ACE AI AGENTS

Statische Cora-AI-Landingpage für GitHub Pages.

## Enthalten
- Premium B2B Landingpage
- Interaktive lokale Cora-Demo
- ROI-Rechner
- Preise: Basic 895 € Setup + 495 €/Monat; Pro 1.495 € Setup + 895 €/Monat; Enterprise auf Anfrage
- Leadformular mit Google Apps Script Endpoint
- Impressum / Datenschutz als Entwürfe

## Wichtige Konfiguration
Vor dem produktiven Einsatz müssen Impressum und Datenschutzerklärung mit den tatsächlichen Unternehmens- und Verarbeitungsdaten ergänzt werden.

Das Frontend enthält keinen KI-API-Key. Die Demo ist bewusst eine lokale Simulation. Für eine echte LLM-Version ist ein serverseitiger API-Endpunkt erforderlich.

## GitHub Pages
Die Website benötigt keine Build-Tools. `index.html` liegt im Root und kann direkt über GitHub Pages veröffentlicht werden.
